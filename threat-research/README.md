## How This Library Is Organized

Each topic gets its own directory. The topic's `README.md` acts as its landing page, with supporting documents for technical analysis, lab notes, detection engineering, response and references.

To add another investigation, create a new folder under `threat-research/` and add it to this index. The main portfolio README links here, so the library can grow without making the portfolio's landing page point to one specific vulnerability.
